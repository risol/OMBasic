# ADR-0001: Use C23 for the reference implementation

Status: Accepted

## Context

The reference implementation needs a portable systems language, explicit ABI boundaries, and checked integer arithmetic. The development plan names C23 and uses <stdckdint.h> for allocation-size arithmetic.

## Decision

Implement the compiler and runtime in ISO C23. A platform is supported only when its selected compiler and C library provide the required C23 facilities or a documented compatibility shim.

The initial validation matrix includes Clang and GCC on Linux and clang-cl on Windows. C++ is limited to external C ABI wrappers.

## Consequences

- CMake targets require C23 with extensions disabled.
- Warnings are treated as errors for project-owned C sources.
- Sanitizer and static-analysis profiles are first-class build options.
- The implementation maintains a Safe C23 profile; use of C23 does not itself guarantee memory safety.
